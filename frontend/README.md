# Frontend: AI-Powered Virtual Clinic App

This directory contains the mobile application source code (React Native/Expo) for the **AI-Powered Virtual Clinic for Rural Healthcare**.

Please refer to the main [Project README](../README.md) for full details on the system architecture, the Doctor Allocation Engine, and the codebase workflow.

## 🚀 Quick Start

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the Expo development server

   ```bash
   npx expo start -c
   ```

## Configuration

Make sure you have created your `.env` file as specified in the main README before starting:

```env
EXPO_PUBLIC_BACKEND_URI="http://localhost:8000"
EXPO_PUBLIC_SUPABASE_URL="your-supabase-url"
EXPO_PUBLIC_SUPABASE_ANON_KEY="your-supabase-anon-key"
```
